# Weekly content KPI

A one-page dashboard for weekly content output, served with GitHub Pages.

- `kpi_log.csv`: one row per week (week starts Monday), plus an optional `note`.
- Points: a motion graphic ad is worth 6 points, a YouTube video 4, an advanced short 2 and a normal short 1.
- The weekly target is 13 points (2 YouTube videos + 5 normal shorts).

To update the dashboard, edit `kpi_log.csv` and push.
